# LIVING CANVAS — Offline Recognition Engine

- **`ShapeRecognizer`**: Computes stroke bounding boxes, aspect ratio, path length, straightness, loop closure, and circularity to classify primitives (`Circle`, `Line`, `Arc`, `Polygon`, `Wave`).
- **`ObjectClassifier`**: Analyses multi-stroke topology 100% offline to classify `stickman`, `car`, `fish`, `bird`, `tiger`, `water`, `cloud`, `ground`, and other categories, outputting part suggestions and confidence scores with manual override support.
